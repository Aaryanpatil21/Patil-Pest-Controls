# Patil Pest Controls - Landing Page

A modern, premium, and fully responsive single-page website built for a pest control business serving Pimpri-Chinchwad and surrounding areas. 

## 🤖 AI-Assisted Learning Project
**Note:** This website was created as a hands-on learning experience to explore web development, responsive web design, and prompt engineering using AI. The code, layouts, and CSS styles were generated and iteratively refined through collaboration with an AI assistant to understand modern web standards.

## ✨ Features
* **🌗 Dual-Theme Interface:** Includes a fully functional Dark/Light mode toggle that saves user preferences locally.
* **📱 Fully Responsive:** Carefully optimized for Desktop, Tablet, Android, and iOS devices with adaptive fluid layouts.
* **🍏 iOS Safari Optimized:** Includes specific CSS and JavaScript fallbacks to prevent iOS WebKit background zooming bugs and local storage blocks.
* **💬 Conversion-Focused:** Features a sticky mobile CTA bar and direct WhatsApp API links pre-filled with customer inquiry text.
* **🎨 Modern Design System:** Built using CSS variables, glassmorphism (`backdrop-filter`), subtle hover animations, and a clean typography hierarchy.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure and layout.
* **CSS3:** Flexbox, CSS Grid, Media Queries, and advanced CSS variables for theme switching.
* **Vanilla JavaScript:** DOM manipulation for the navigation scroll effect and theme toggling logic.

## 🚀 How to View
Since this is a static website, no installation is required! 
1. Simply clone or download the repository.
2. Open the `index.html` file in any modern web browser.
3. Or, visit the live site via GitHub Pages: https://aaryanpatil21.github.io/Patil-Pest-Controls/
